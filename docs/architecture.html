Catalyst Components: System Architecture

A factory inventory management demo. It's a Vue 3 single-page app talking to a Python FastAPI service that serves mock data from JSON files held in memory. There is no database.

Data flow: changing a filter

  1. The user picks a filter in FilterBarTime Period, Location, Category or Order Status. These live in useFilters.js as shared module-level refs, so every view sees the same values.
  2. The view notices the change and fetches againFor example, Dashboard calls getCurrentFilters() and then api.getOrders(), api.getInventory() and api.getDashboardSummary().
  3. api.js builds the requestEach filter that isn't "all" becomes a query param, giving something like GET /api/orders?warehouse=San%20Francisco&month=Q2-2025.
  4. FastAPI filters the in-memory listsapply_filters() matches warehouse, category and status. filter_by_month() matches a month string, or a quarter such as Q1-2025 using QUARTER_MAP.
  5. Pydantic validates the result and FastAPI returns JSONResponses are typed as InventoryItem, Order, BacklogItem and so on. The summary and spending endpoints return plain dicts.
  6. Vue updates the screenRaw data goes into refs such as allOrders and inventoryItems. KPIs, charts and tables are computed from them and redraw automatically.

Project structure

client/src/

  • main.js: sets up the app and routes
  • App.vue: shell, top nav, global styles
  • api.js: HTTP client
  • views/: one file per page
  • components/: FilterBar and modals
  • composables/: filters, i18n, auth
  • locales/: en and ja strings

server/

  • main.py: app, models, routes, filters
  • mock_data.py: loads the JSON
  • data/*.json: the data itself
  • generate_data.py: builds the data

Repository root

  • tests/backend/: pytest suites
  • scripts/: start and stop
  • .claude/: agents, commands, hooks
  • CLAUDE.md: project instructions

Observations

Gaps found while reading the code
  • api.js calls /api/tasks and /api/purchase-orders, but the backend doesn't define either, so those requests return 404.
  • views/Backlog.vue exists but has no route in main.js, so you can't reach it in the app.
  • Reports.vue calls axios directly instead of going through api.js.
  • The API base URL is hard-coded to localhost:8001, and CORS allows every origin. That's fine for a demo but not for production.
  • Quarter filtering only covers 2025, because QUARTER_MAP is hard-coded.
